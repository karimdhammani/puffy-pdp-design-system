01  /  Principles

Four rules that keep pages consistent.

  1. Semantic over raw

    A component asks for --fill-cta, never #2b2f44. Rebrand, dark mode, and a seasonal promo all become edits to one file instead of a find-and-replace across every page.

  2. Serif speaks, sans informs

    PT Serif carries voice — product names, headlines, price. Mukta carries information — specs, labels, helper text. A page that mixes the two jobs reads as two brands.

  3. One primary action per view

    There is exactly one .pf-btn--lg.pf-btn--primary on screen at a time. Everything competing with Add to Cart is --secondary or --quiet.

  4. Accessible by construction

    Focus rings, target sizes, and contrast are properties of the tokens, not a pass at the end. Every pairing on this page states its measured ratio.

02  /  Colour

Roles, not hex codes.

Two tiers. The ramp below is raw material; the roles beneath it are what you actually reach for. Every ratio on this page is measured in the browser from the live token value — change a token and the number changes with it.

05  /  Effects & motion

Five shadows, two easings.

Elevation is scarce on purpose — a page where everything floats has no hierarchy. All motion is short, eased, and cut entirely under prefers-reduced-motion.

06  /  Iconography

Original marks. Consistent use.

Extracted from the source page and kept as editable SVG. Size through .pf-icon--* so icons never drift off the grid. An icon-only control always carries a text label for screen readers.

Marks on navy tiles are single-colour light: they came off the dark navbar, the See Inside panel, or the USP bar, and will disappear on a white ground. Where a benefit needs both grounds the set carries a pair — cooling-cloud and cooling-cloud-white. Anything drawn on a white tile is safe on light surfaces.

08  /  Accessibility

WCAG 2.2 AA, built into the tokens.

These are commitments the system enforces, not a checklist someone runs at the end.

1.4.3 · Contrast

Every approved pairing is measured on this page. Two tokens are deliberately restricted: --highlight-soft is dark-grounds-only, and --brand is large-text-and-non-text only.

1.4.11 · Non-text contrast

The softest border in the system, --border-sub-strong, measures 3.35:1 on white — clearing the 3:1 requirement for component boundaries.

2.4.13 · Focus appearance

One ring, defined once in 02-base.css, inverted on dark grounds. Tab through this page — nothing loses its outline.

2.5.8 · Target size

Controls design to a 44px target. .pf-target extends the hit area of a small control without changing how it looks.

2.3.3 · Animation from interaction

Nothing in the system depends on motion to convey meaning, so prefers-reduced-motion cuts all of it safely.

4.1.2 · Name, role, value

Selectors are radiogroups, disclosures are <details>, icon-only controls carry .pf-sr-only text.
